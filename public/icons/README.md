# PWA icons

Placeholders generated for installability:

- `icon-192.png` / `icon-512.png` — standard
- `icon-512-maskable.png` — Android adaptive (extra safe padding)
- `apple-touch-icon.png` — iOS home screen

Replace these with your final brand mark (same sizes) when ready. Keep filenames so `app/manifest.ts` and metadata keep working.
